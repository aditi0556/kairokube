The handoff pipeline

Nine supervised phases, one consistent end state

Each phase reports its own duration back into these cards as a migration runs. The adaptive cutoff is computed from measured λ and μ, not a fixed timer.

01 / CHECKPOINT

Freeze the source

The kubelet is asked to checkpoint the source container, producing a CRIU archive of memory, fds and sockets.

Last duration–
02 / TRANSFER

Move the artifact

The archive is copied to the target with a SHA-256 verified transfer, so a truncated file can never be restored.

Last duration–
03 / RESTORE + REPLAY

Rebuild the process

The target container starts from the archive, then RabbitMQ messages queued before the cutoff are replayed and deduplicated.

Replay duration–
04 / CUTOVER

Swap and verify

Traffic shifts once replay has drained the backlog, the old pod is released, and the result is verified end to end.
